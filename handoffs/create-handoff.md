# Create and verify a handoff

## Before ending a session

Update `handoffs/current.md` with the current project purpose and root path, files created or changed, checks run with commands and observed results (including failures), outstanding questions or approvals, and the next concrete task. Do not include credentials or other secrets.

## When resuming work

Read `handoffs/current.md`, inspect the current files and Git status when available, compare them with the recorded state, and rerun the listed checks before relying on the handoff; update the handoff if the actual state differs.
