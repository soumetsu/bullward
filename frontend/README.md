# Frontend

This is the Vue 3 and Vite frontend for Project 4 Invest. It displays the API's synthetic one-minute sample with Lightweight Charts 5.2.1, aligned volume, a candle inspector, and a data table. It forwards `/api` requests to FastAPI.

From this directory, run `npm install` to restore dependencies, `npm run dev -- --host 127.0.0.1 --port 5175` to start the UI, and `npm run build` to create the production bundle. See the root `README.md` for backend startup and API URLs.
